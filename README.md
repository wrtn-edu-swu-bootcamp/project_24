# 🏥 건강 체크 앱

병원에 가기 애매하게 아프거나 병원을 가기 전에 간단하게 자기 몸을 진단할 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 1. 증상 체크
- 일반적인 증상 선택 (두통, 발열, 복통 등)
- 증상 심각도 및 지속 시간 입력
- AI 기반 긴급도 분석 및 권장사항 제공
- 병원 방문 필요성 판단

### 2. 병원 찾기
- 가까운 병원/응급실 검색
- 실시간 진료 가능 여부 확인
- 예상 대기 시간 표시
- 거리순 정렬
- 병원 유형별 필터링 (응급실/종합병원/클리닉)
- 길찾기 및 전화 연결 기능

### 3. 건강 기록
- 과거 증상 체크 기록 저장
- 기록 상세 정보 확인
- 증상 패턴 분석

## 기술 스택

- **Frontend**:** React 18 + TypeScript + Vite
- **Styling**: CSS3 (모던 그라데이션 디자인)
- **Routing**: React Router
- **Icons**: Lucide React

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 향후 개선 사항

1. **실제 병원 데이터 연동**
   - 공공데이터포털 보건복지부 병원 정보 API 연동
   - 실시간 진료 가능 여부 API 연동

2. **위치 기반 서비스**
   - 사용자 GPS 위치 자동 감지
   - 거리 계산 및 최적 경로 제공

3. **지도 통합**
   - 네이버 지도/카카오맵 API 연동
   - 병원 위치 시각화

4. **AI 개선**
   - 더 정교한 증상 분석 알고리즘
   - 머신러닝 기반 진단 지원

5. **추가 기능**
   - 약물 복용 기록
   - 병원 예약 시스템 연동
   - 건강 통계 및 차트
